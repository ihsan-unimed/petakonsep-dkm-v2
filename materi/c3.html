Langkah 3 · Teori kegagalan

Pertemuan 6 · Sub-CPMK 2.3 · Tresca vs von Mises + contoh poros M=150 N·m T=200 N·m d=30 mm

1. Mengapa perlu teori kegagalan

  • Uji tarik hanya memberi satu angka Sy, padahal titik kritis poros menerima lentur (σ) + puntir (τ) sekaligus.
  • Teori kegagalan menggabungkan σ dan τ menjadi satu tegangan ekuivalen σ' yang bisa dibandingkan dengan Sy.
  • Prosedur 5 langkah: (1) tentukan penampang kritis + beban M,T → (2) hitung σ,τ → (3) hitung σ' → (4) n=Sy/σ' → (5) aman jika n ≥ nd.

2. Tresca vs von Mises (material ulet)

  • Tresca (tegangan geser maksimum): luluh saat tegangan geser maksimum = geser saat luluh pada uji tarik. Sifat: konservatif — memprediksi luluh sedikit lebih cepat dari kenyataan, cocok untuk cek cepat manual.
  • von Mises (energi distorsi): luluh saat energi distorsi (pengubah bentuk) per volume = energi distorsi saat luluh. Sifat: lebih akurat untuk logam ulet, standar di CAD/FEA.
  • Aturan praktis: Tresca untuk hitungan tangan yang aman; von Mises untuk analisis teliti dan hemat material.
  • Keduanya hanya untuk material ulet terhadap luluh. Material getas: tegangan normal maksimum, Coulomb-Mohr, Mohr termodifikasi.
Tresca: σ' = √(σ² + 4τ²) n = Sy / σ' von Mises: σ' = √(σ² + 3τ²) n = Sy / σ' Bedanya hanya koefisien τ²: 4 (Tresca) vs 3 (von Mises).

3. Contoh soal lengkap (M=150 N·m, T=200 N·m, d=30 mm, AISI 1045 Sy=310 MPa, nd=2,5)

Langkah 1–2 — tegangan di penampang kritis (konversi N·m → N·mm ×1000):

σ = 32M/(πd³) = 32×150.000/(π×30³) = 4.800.000/84.823 = 56,6 MPa τ = 16T/(πd³) = 16×200.000/(π×30³) = 3.200.000/84.823 = 37,7 MPa

Langkah 3a — Tresca:

σ'Tresca = √(56,6² + 4×37,7²) = √(3203+5686) = √8889 = 94,3 MPa n = 310/94,3 = 3,29 ≥ 2,5 → AMAN

Langkah 3b — von Mises:

σ' = √(56,6² + 3×37,7²) = √(3203+4264) = √7467 = 86,4 MPa n = 310/86,4 = 3,59 ≥ 2,5 → AMAN (margin lebih besar, sesuai teori)

Cross-check tegangan utama: σ₁,₂ = σ/2 ± √((σ/2)²+τ²) = 28,3 ± 47,2 → σ₁=75,4 MPa, σ₂=−18,9 MPa. 2×τmaks = 2×47,2 = 94,3 MPa = σ'Tresca ✓

Keputusan: kedua kriteria sepakat AMAN, tidak perlu redesain. Jika n < 2,5 → perbesar d, ganti material Sy lebih tinggi, atau kurangi beban.

4. Verifikasi di Excel (metode RPS)

  1. Isi sel berlabel: M=150, T=200, d=30, Sy=310, nd=2,5.
  2. Lentur: =32*M*1000/(PI()*d^3) → σ (MPa).
  3. Puntir: =16*T*1000/(PI()*d^3) → τ.
  4. Tresca: =SQRT(sigma^2+4*tau^2); von Mises: =SQRT(sigma^2+3*tau^2).
  5. n: =Sy/sigma_prime; status: =IF(n>=n_req,"AMAN","REDESAIN").
