Roda gigi

Pertemuan 10–11 · Sub-CPMK 4.1 · Geometri, gaya, Lewis + iterasi 12 kW

1. Konsep & jenis

  • Roda gigi meneruskan daya antarporos lewat gigi berkait: tanpa slip, rasio tetap, efisiensi ±95–98% per pasang, cocok jarak sumbu pendek; butuh presisi + pelumasan; gaya gigi membebani poros/bantalan.
  • Lurus (spur): poros sejajar, murah, bising di rpm tinggi. Miring (helical): halus, ada beban aksial. Kerucut (bevel): poros berpotongan 90° (gardan). Cacing (worm): bersilangan, rasio 10–100 satu tahap, efisiensi rendah.

2. Geometri (sistem modul)

d = m·N p = π·m a = m b = 1,25m do = d+2m F ≈ (3–5)·p i = N2/N1 = n1/n2 C = m(N1+N2)/2 Syarat pasang: m sama + sudut tekan φ sama (umum 20°). Modul standar: 1; 1,25; 1,5; 2; 2,5; 3; 4; 5; 6; 8; 10. Pinion φ=20°: N1 ≥ 18 (cegah undercut). Rasio 1 tahap ≤ 6.

Contoh 1: N1=20, N2=60, m=3, n1=1.450 → d1=60, d2=180 mm; i=3; n2=483 rpm; C=120 mm; p=9,42 mm; F≈28–47 mm.

3. Gaya gigi

V = π·d·n/60.000 (m/s, d mm) Wt = P/V = 2T/d (tangensial → tegangan gigi) Wr = Wt·tanφ W = Wt/cosφ (radial → beban poros)

Contoh 2 (P=5 kW): V=π×60×1.450/60.000=4,56 m/s; Wt=5.000/4,56=1.098 N; Wr=1.098×tan20°=400 N; W=1.168 N; T1=32,9 N·m. Wt+Rr masuk diagram geser poros.

4. Lewis + faktor keamanan

σ = Kv·Wt/(F·m·Y) Kv = (6,1+V)/6,1 (gigi frais) n = Sy/σ ≥ nd ≈ 3 (Lewis kasar, belum lelah/kontak)

Tabel Y (φ=20°): N12→0,245; 15→0,290; 18→0,309; 20→0,322; 25→0,340; 30→0,359; 40→0,389; 60→0,422; 100→0,447.

Material (Shigley A-20): 1020 HR Sy=210; 1030 HR 260; 1040 CD 490; 1045 CD 530; 1050 CD 580 MPa. Pinion dibuat lebih kuat (siklus lebih banyak).

Contoh 3: Wt=1.098, V=4,56, m=3, F=30, Y=0,322, 1020 HR → Kv=1,75; σ=1,75×1.098/(30×3×0,322)=66,2 MPa; n=210/66,2=3,17 ≥ 3 ✓ tipis.

Contoh 4 (naik 12 kW, dimensi sama): Wt=2.634 N; σ=158,8 MPa; n=1,32 < 3 ✗. Perbaikan: (A) m=4,F=40 → n=2,74 belum aman; (B) tetap m=3 ganti 1045 CD → n=3,34 ✓ paling murah (casing tetap); (C) keduanya → n=6,93 overdesign.

Mode gagal: patah lentur (Lewis), pitting (Hertz/AGMA), aus/scoring (pelumasan).

5. Latihan (kunci di PPT)

  1. N1=18, N2=54, m=2,5 → d1, d2, i, C.
  2. P=3 kW, n1=960 → V, Wt, Wr.
  3. F=25, 1045 CD, Y=0,309 → σ, n (nd=3)?
  4. Tiga cara naikkan n tanpa ubah rasio + konsekuensinya.
