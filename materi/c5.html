Langkah 5 · Keputusan

Langkah 5 dari 5 · Keputusan + iterasi desain

1. Aturan

n ≥ nd → AMAN n < nd → TIDAK AMAN → ubah d/m/F/material/beban, hitung ulang dari Langkah 1

2. Contoh

  • Gigi 12 kW: n=1,32 < 3 → iterasi: ganti material 1045 CD → n=3,34 ✓ (casing tetap, paling murah).
  • Keling Ø10: n=1,66 ✗ → Ø12: n=2,39 ✓.
  • n raksasa (baut 28, las 88) belum tentu baik: boros, berat — tetapi jangan asal kecilkan (getar, standar, ketersediaan).
