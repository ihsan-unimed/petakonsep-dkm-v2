Sabuk-puli & rantai

Pertemuan 12 · Sub-CPMK 4.2 · Sabuk-V + rantai rol + K3

1. Kapan sabuk / rantai

  • Transmisi fleksibel untuk poros berjauhan tanpa rangkaian gear panjang.
  • Sabuk: redam kejut, murah, senyap, bisa slip ±1–2% (kecuali timing); Rantai: tanpa slip, kuat beban besar rpm rendah, perlu pelumasan, bising.
  • Jenis sabuk: datar (rpm tinggi, jarak jauh), V (terjepit di alur → gesek besar; industri/pertanian), bergigi/timing (tanpa slip; mobil/CNC).

2. Geometri sabuk

n1/n2 = D/d θ = π − 2·sin⁻¹((D−d)/2C) (rad, puli kecil) L ≈ 2C + π(D+d)/2 + (D−d)²/4C → bulatkan ke standar Pedoman: θ ≥ 120° (sabuk-V); D/d ≤ 6–7; D < C < 3(D+d)

Contoh 1: d=100, D=250, C=500, n1=1.450 → n2=580 rpm; θ=π−2(0,1506)=2,84 rad=162,7° ✓; L=1.561 mm → standar ±1.560.

3. Gaya sabuk → beban poros

T = (F1−F2)·d/2 P = (F1−F2)·V F1/F2 = e^(fθ) datar = e^(0,5123θ) sabuk-V Fb ≈ F1+F2 (jauh > F1−F2 → inilah beban poros!)

Contoh 2 (P=3 kW, θ=2,84): V=π×0,1×1.450/60=7,59 m/s; F1−F2=3.000/7,59=395 N; rasio=e^(0,5123×2,84)=4,29; F2=395/3,29=120 N; F1=515 N; Fb=636 N (≈1,6× gaya efektif) → dipakai desain poros & bantalan. Sabuk terlalu kencang → Fb naik → bantalan cepat rusak.

4. Jumlah sabuk-V

Pd = Pnom·Ks·nd Nb ≥ Pd/Pa nfs = Nb·Pa/(Pnom·Ks) ≥ nd (umum 1,0–1,2)

Ks: seragam 1,0–1,2; kejut ringan 1,1–1,3; sedang (pencacah) 1,2–1,4; berat 1,3–1,5.

Contoh 3 (3 kW, Ks=1,2, nd=1,1, Pa=2,2): Pd=3,96; 1 sabuk nfs=0,61 ✗; Nb=2 → nfs=1,22 ✓.

Mesin pencacah: P=2,2 kW, d=90, D=180, C=400 → n2=720 rpm, V=6,79 m/s, F1−F2=324 N, θ=2,92 rad, rasio=4,45, F2=94, F1=418, Fb=512 N; Pa=1,3 Ks=1,3 → 2 sabuk nfs=0,91 ✗, 3 sabuk nfs=1,36 ✓.

5. Rantai rol

D = p/sin(180°/N) V = N·p·n/60.000 L/p ≈ 2C/p + (N1+N2)/2 + (N2−N1)²/(4π²C/p) → genap F = P·Ks/V n = Fu/F ≥ nd ≈ 7 ISO: 08A p=12,7 Fu=13,9 kN; 10A p=15,875 Fu=21,8; 12A p=19,05 Fu=31,3; 16A p=25,4 Fu=55,6. Duplex ≈ 2×.

Contoh 4 (P=2 kW, n1=300, N1=17, N2=34, Ks=1,3): 08A → D1=69,1 mm, V=1,08 m/s, F=2.409 N, n=5,8 < 7 ✗ → 10A: V=1,35, F=1.927, n=11,3 ✓. N1 minimal 17 (chordal action); C umum 30–50p.

6. Tips, K3, inovasi

  • Sisi kencang di bawah; sediakan tensioner/rel motor; puli sejajar sebidang.
  • K3: wajib guard sabuk & rantai; lockout sebelum menyetel; cek retak/mulur berkala.
  • Inovasi: kit transmisi UMKM siap pasang; tensioner pegas otomatis; modul perawatan SMK.
